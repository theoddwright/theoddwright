# Odd Wright

Game designer at Last Hope Games.

Every game we make follows one rule: a single great light carries the world, and you can read the round in it.

**Deepwater** is our first, and a deliberate test: one rig, one painted sea, one decision before each dive.
Small enough to get every part right, and to learn what it takes to bring a game to Stake.

Maths you can check: every mode's return, odds and top prize are in the rules, before you play. 18+
